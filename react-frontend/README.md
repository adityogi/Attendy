# ClassTrack React Port

To run this React application locally, you will need to have [Node.js](https://nodejs.org/) installed on your system.

1. Open a terminal in this folder (`react-frontend`).
2. Run `npm install` to install dependencies.
3. Run `npm run dev` to start the local development server.

## Vercel Deployment
You can connect this folder directly to a Vercel project. Vercel automatically detects Vite/React apps and will run `npm install` and `npm run build` for you!
